# Image Classification Project

Project klasifikasi gambar menggunakan CNN sederhana.

Dataset:
https://www.kaggle.com/datasets/kausthubkannan/5-flower-types-classification-dataset

Model menggunakan:
- Resize gambar 128x128
- Normalisasi piksel
- Data augmentation
- CNN dengan Conv2D, MaxPooling2D, Flatten, Dense, dan Output Softmax
